# analise-lucro-retorno

Página pública (GitHub Pages) que só repassa o código de autorização do Mercado Livre para o programa
`analise-lucro-ml`, que roda no computador do usuário em `http://localhost:3220`.

O Mercado Livre não aceita `localhost` como URI de redirect; por isso o app do ML aponta para
`https://thyagogrecu.github.io/analise-lucro-retorno/`. Esta página não guarda nada.
